Política de privacidade

Bella, agente de IA do Master Data · atualizada em 09/10/2026

Quais dados a Bella usa

  • Dados das solicitações de cadastro no Webformat: número, tipo de material, descrições, NCM, fabricante, referência, aplicação e os grupos de mercadorias e de compradores.
  • Respostas do time às perguntas dela: a opção escolhida, o texto escrito e, se a pessoa informar, o nome de quem respondeu.
  • Mensagens enviadas diretamente à Bella no Teams, quando ela é chamada.

O que ela não usa

  • Não lê e-mails, arquivos nem conversas que não sejam dirigidas a ela.
  • Não guarda nome, e-mail ou matrícula dos solicitantes do Webformat.
  • Não envia dados pessoais ao serviço de IA: só o texto técnico do material.

Onde os dados ficam

  • Banco de dados no Supabase, na região de São Paulo (Brasil), com acesso restrito à chave do sistema.
  • A análise do texto dos materiais usa a API do Claude (Anthropic), que não usa os dados enviados pela API para treinar modelos.

Para que servem

Somente para a triagem de cadastros e para a consulta de grupos pelo time de Master Data. Os dados não são vendidos nem compartilhados com terceiros.
